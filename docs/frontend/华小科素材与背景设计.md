## 设计结果：树荫下，开启新的世界

- 角色：保留粉色低双马尾、呆毛、蓝色发饰 / 丝带、粉瞳、白蓝外套与深蓝领带；重画为坐在石墙上读书、轻轻挥手的 Q 版形象。
- 环境：暖纸底、灰绿树冠、浅赭石墙和远处的校园建筑。方形步道只暗示建造游戏，不采用游戏纹理或商标。
- 色彩：延续 `#F4F0E7` / `#FFFCF6` 纸底和 `#8C1D2F` 主操作；新增粉发 `#D98D9B`、蓝灰 `#4C647B`、叶色 `#CCD8C4`。新增颜色属于插画，业务成功 / 错误语义不变。
- 首页：226 × 280 右侧背景展示角色，状态和启动摘要保持在左侧实色表面；下方保留设置、日志入口。侧栏只取远景，避免重复出现半张人脸。
- 安装页：将同图的角色区域放到导航下方的空白处，保留步骤、路径、恢复说明和取消入口。小科是陪伴背景，不表示真实下载进度。
- 页头：四枚低对比度叶形，只占右上留白；不把放大的半张人脸放在标题后面。
- 无动画、在线图片或外部字体；装饰忽略指针事件。原生演示提供 `--no-decoration` 隐藏插画、叶形和侧栏图片；Windows 高对比度、屏幕阅读器与完整键盘逐项验收仍未完成。

生成 PNG 原稿保存在本机图像工具输出目录，未进入 Git；只做 JPEG 编码转换用于评审，没有额外改变构图。原生程序从 qrc 加载同一 JPEG；设计 HTML / SVG 从相对路径或内嵌副本加载。对比页的内嵌副本不作为新的素材源。

更新流程：替换共享 JPEG → `python tools/sync_mockup_art.py` → 重建对比页 → 渲染审阅 → 提交。同步只读检查：`python tools/sync_mockup_art.py --check`。

重建当前 Oil UI 对比页（需要本机已有的 `dsh-oil-ui@0.3.2`）：

```powershell
python "$env:USERPROFILE/.dsh/profiles/web/node_modules/dsh-oil-ui/skills/oil-ui/scripts/build_explorer.py" resources/mockups/oil-ui/manifest.json --force
```

原生 `CampusArtwork` 只加载一份 JPEG 并以 `QPixmapCache` 缓存解码结果，在装饰区域裁切绘制；首页右列与安装页侧栏共用同一资源。不要把完整 HTML / SVG 页面作为界面，也不要为不同任务状态生成图片。原图一次 RGBA 解码的理论尺寸约 6 MiB，这是估算，尚未做完整 Qt 内存基准；`hustmcl_ui_tests` 验证缓存键存在和重复渲染控件数不增长。JPEG 选择兼顾常见 Qt 图像支持与体积，不为背景引入 WebP、QtSvg 或新皮肤框架。
