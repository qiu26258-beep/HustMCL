## 2. 约束引用与不可违反的边界

产品范围、目标平台、性能目标和里程碑以 [MVP 项目规划](../MVP项目规划.md) 为准；模块依赖、数据约定、任务状态与失败恢复以 [架构设计](../架构设计.md) 为准；构建与测试边界以 [构建与测试](../构建与测试.md) 为准。本文只写界面决定，不重复主规划中的平台与性能论证。

### 2.1 UI 只消费应用快照

| UI 可以做 | UI 不得做 |
| --- | --- |
| 展示 application 提供的只读快照 | 解析版本 JSON、资源列表或安装清单 |
| 把稳定枚举 / 错误码映射为中文文案 | 比较 Java 主版本、架构或判断版本兼容性 |
| 格式化已给出的字节、路径和版本标签 | 自行计算安装阶段、下载总量或可用空间 |
| 根据快照决定控件可见、可用和焦点 | 根据账号 / 实例 / Java 三个布尔值自行推导主操作 |
| 维护焦点、滚动、未保存草稿等界面局部状态 | 维护第二份“安装中”“已登录”业务状态 |
| 打开文件选择框并交给 application 校验 | 规范化路径、拼接数据目录或判断写权限 |
| 请求登录、安装、取消、重试、保存等命令 | 判断错误是否可重试、解析异常文本或读取凭据 |

原则：**快照没有提供的数据，显示“未知 / 待应用层提供”，不猜测。** 版本、Java、安装和路径规则属于 core / application；UI **不复制**版本 / Java / 安装规则，主按钮由 application 给出的 `PrimaryAction` 决定。

账号授权、安装就绪、游戏进程是三种独立状态。安装就绪不等于进入主菜单；游戏退出不得触发重新安装；取消、重试或切换实例后，按 `taskId` 忽略过期通知。

### 2.2 原生实现与资源

- 产品技术栈是 C++20 + Qt 6 Widgets；HTML 候选和对比页只用于设计评审，不进入产品，不引入 WebView、QML、JS 应用或本地 Web 服务。
- 默认 Windows 系统标题栏，不做无边框窗口；不使用大型皮肤库、持续动画、远程字体或远程图片。
- 图标与叶形由项目绘制；本批按用户要求采用华小科角色衍生设计，不复制学校校徽，不声称官方背书。素材来源与授权边界单独记录；不挪用 PCL / HMCL 图标、主题或截图。
- `resources/mockups/` 是评审稿，不是运行时皮肤。生产界面由 Qt 控件渲染，避免整页预览图带来的 DPI 模糊、不可访问和无法本地化。

## 3. 方向探索与推荐

### 3.1 三个方向

| 方向 | 首屏骨架 | 字体 / 色彩 | 主视觉与记忆点 | Qt 表达 | 主要风险 |
| --- | --- | --- | --- | --- | --- |
| **Campus Desk**（推荐） | 216 编号侧栏 + 一张 840 桌面；桌面内左为实例 / 状态 / 摘要，右为华小科插画 / 快捷入口；底部固定主操作 | 微软雅黑 UI；暖纸 `#F4F0E7`、桌面 `#FFFCF6`、深红 `#8C1D2F`、墨 `#23201C` | 华小科树荫插画与校园远景；编号目录；桌面底边的“开始”位置 | `QListWidget` + `QVBoxLayout` + `QFrame#Desk` + `QGridLayout` + `PrimaryActionBar` | 暖纸色容易落回“米色模板”，需靠单一桌面、编号和角色背景保持具体 |
| **Launch Deck** | 顶部导航 + 暗色启动带（实例名 + 主按钮 + 门廊）+ 三列状态轨；无侧栏 | Bahnschrift + 微软雅黑 UI；冷底 `#EFF3F4`、暗带 `#17282C`、红 `#B23A2E`、青 `#1F5C5A` | 三根红柱的门廊；暗带里的主按钮 | 顶部 `QToolBar` / `QHBoxLayout` + 暗色 `QFrame` + `QGridLayout` | 视觉更强，但导航位置改变、暗色面板增加实现与对比度成本 |
| **Field Guide** | 168 章节栏 + 856 纸面；纸面左为实例 / 状态 / 主按钮，右为线稿 / 摘要 | SimSun 标题 + 微软雅黑 UI 正文 + Georgia 数字；纸底 `#ECEDDF`、纸面 `#FCFCF2`、印章红 `#A33A2B` | 教学楼与梧桐线稿；H 方印；章节编号 | 窄 `QListWidget` / `QTabBar` + `QScrollArea` + 纸面 `QFrame` | 更像阅读页面，启动器任务感较弱；宋体回退与 200% 缩放风险高于 A |

设计调性共用：安静、精确、友好，不幼稚；能量偏安静，完成度偏精致，密度中等，分量中等，严肃度偏庄重。三个方向都保留一个主操作和清楚的安装状态，不堆装饰、动画或彩色徽章。

标杆说明：本轮阅读了项目内对 PCL / HMCL 的架构记录，但**没有抓取或复用两者的运行画面、图标或主题素材**，也没有把其界面当作复刻目标。方向判断来自本产品的受众、安装等待场景和校园主题；不声称做过 PCL / HMCL 的像素级拆解。

### 3.2 为什么暂定推荐 Campus Desk

1. **维护成本最低**：编号导航、桌面、状态行、固定主操作条都能用标准 Qt Widgets 表达；不需要暗色自绘面板、宋体标题或横向仪表布局的特殊约束。
2. **新手最易懂**：左侧固定导航 + 一个主操作 + 三行准备状态；不需要先理解顶部导航或章节结构。
3. **资源可控**：纯色、细线和一张共享静态 JPEG（约 604 KiB）；复用同图裁切，不引入远程资源或持续动画。Qt 解码与内存需在真实界面中实测。
4. **校园识别明确**：暖纸、深红、编号目录、华小科与树荫远景形成同一语言；参考图不直接搬入产品，角色权利单独记录。
5. **能延续到安装页**：同一张桌面可以变成“垂直步骤 + 本次安装 + 底部取消条”，状态语义不需要另造组件。

Launch Deck 的启动带更有冲击力，适合后续可选视觉方向；Field Guide 的手册感更强，但更像阅读产品。两者不删除，保留在对比页。

## 4. 全局框架

### 4.1 窗口骨架

```text
┌──────────────────────────────────────────────────────────────┐
│ Windows 系统标题栏（最小化 / 最大化 / 关闭由系统绘制）          │
├──────────────┬───────────────────────────────────────────────┤
│ 编号侧栏 216 │ 页面标题 / 一句说明（固定）                     │
│ 01 首页      ├───────────────────────────────────────────────┤
│ 02 安装游戏  │ 内容（QScrollArea，可纵向滚动）                 │
│ 03 设置      │                                               │
│ 04 日志      ├───────────────────────────────────────────────┤
│              │ 固定主操作条（安装页为取消入口）                 │
└──────────────┴───────────────────────────────────────────────┘
```

结构：`QMainWindow` → 中央 `QWidget` → `QHBoxLayout`（216 侧栏 + 右侧页面容器）。右侧为 `QVBoxLayout`：页面标题、`QScrollArea`、固定主操作条。四页共用 `PageScaffold`，不各写一套边距和滚动逻辑。

导航用 `QListWidget`（单选、46 行高、编号 + 文本）；选择它而不是自绘按钮，是为了方向键、焦点和可访问性语义。编号是文案的一部分，不用通用图标库。

### 4.2 尺寸与响应式

- 设计画布：1120 × 720 逻辑像素；最终 SVG 使用同一画布。
- 实现默认窗口：1120 × 720 逻辑像素；启动时钳制到当前屏幕可用工作区并预留边距。
- 最小窗口：840 × 460 逻辑像素；低于此尺寸不保证可用。
- 断点：宽度 ≥ 1120 使用双列桌面；< 1120 改为单列，桌面内容纵向滚动。判断依据是窗口宽度，不是物理分辨率。
- 页面标题和主操作条固定在滚动区外；200% 缩放下主操作仍可见。
- 侧栏在 ≥ 960 时宽 216，< 960 时宽 200；导航文字不截断。
- 长路径用 `QFontMetrics::elidedText` 中间省略，并在只读输入框 / tooltip 中保留完整值；不改写中文、空格或反斜杠。

## 5. 页面规格

### 5.1 首页（Campus Desk）

**目标**：新手打开后 5 秒内知道“我是谁、当前实例是什么、是否准备好、下一步做什么”。每屏只有一个主操作。

**信息层次**

1. 问候与当前实例：`下午好，林知远`、`校园生存 · Minecraft 1.21.4`；右侧是样例时间。
2. 准备状态：账号、Java 运行时、游戏实例三行；每行有勾选圆点、名称、值、状态。状态来自快照，不由 UI 判断。
3. 启动摘要：内存上限、启动后行为；说明“启动器关闭后，游戏会继续运行”。
4. 小提示：设置入口、日志与错误入口；不堆额外卡片。
5. 固定主操作条：`准备就绪` + `启动游戏`；次操作只保留“安装其他版本”。
6. 页脚：一行样例数据说明 + 系统标题栏说明。

**布局**：216 侧栏 + 248 起的 840 桌面（1120 画布）；桌面顶部是实例名与元信息；左列三行状态 + 启动摘要；右列华小科树荫背景 + 陪伴文案 + 两个链接；桌面底部是 80 px 主操作条。

**Qt Widgets 分工**

| 区域 | 组件 | 说明 |
| --- | --- | --- |
| 侧栏 | `QListWidget` | 01–04 编号 + 文本；当前行红底、左侧红条 |
| 问候 | `QLabel#Greeting` | 30 px / 22.5 pt；账号名来自快照 |
| 实例 | `QLabel` × 2 | 实例名 + 版本标签；不做兼容性判断 |
| 准备状态 | `StatusRow` × 3 | 勾选圆点 + 名称 + 值 + 状态；颜色不是唯一信息 |
| 启动摘要 | `SummaryRow` × 2 | 内存、启动后行为；来自快照 |
| 陪伴与快捷入口 | `QLabel` + 两个扁平 `QPushButton` | 陪伴文案不表示业务进度；设置、日志入口 |
| 主视觉 | `QWidget#CampusIllustration` | 一份共享 JPEG + 静态叶形；缓存图像并在装饰区域裁切，不加载整页 SVG；不为图片引入 QtSvg 等新模块 |
| 主操作 | `PrimaryActionBar` | 文案由 `PrimaryAction` 映射；禁用时旁注原因 |

**状态**

- 未登录：问候改为“登录后开始”，状态行显示“等待登录”，主按钮“登录”。
- 无实例：状态行显示实例缺失，主按钮“安装游戏”；不伪造实例。
- Java 未就绪：主按钮“准备环境”；说明会获取或选择运行时，不展示未确认的下载地址。
- 游戏运行中：主按钮“游戏运行中”禁用；可查看日志；MVP 不增加“结束游戏”。
- 错误：显示可理解的摘要和下一步；重试只按 `AppError.retryable` 出现。

**键盘**：初始焦点在主操作；Tab 经过侧栏、设置链接、日志链接、主按钮；Enter / Space 激活；Esc 不执行破坏性动作。

### 5.2 安装游戏

**目标**：让用户确认“装哪个版本、装到哪里、现在到哪一步、如何安全取消”，同时不伪造进度。

**信息层次**

1. 页面标题与阶段：`安装游戏`、`为校园生存准备 Minecraft 1.21.4`、`阶段 4 / 6`。
2. 左列垂直步骤：未安装 → 解析版本 → 准备环境 → 下载文件 → 校验文件 → 就绪；完成 / 当前 / 未来三种状态。当前下载行展开“总量未知 · 已传输 128.4 MB”。
3. 右列：版本 1.21.4（推荐 / 已验证）、目录、空间、取消与恢复、完成后的边界。
4. 固定底栏：`安装进行中` + `下载文件 · 总量未知 · 已传输 128.4 MB` + **唯一**的“取消安装”。
5. 页脚：样例数据说明 + 系统标题栏说明。

**阶段与进度**

- 阶段名由 application 枚举映射；UI 不用文件数量或耗时猜阶段。
- `totalBytes` 有值：可以显示确定进度、已传输 / 总量、百分比；百分比由已完成 / 总量得出，不额外估算。
- `totalBytes` 为空：只显示阶段、已传输量、当前子阶段；**不显示百分比、不显示假进度条、不使用循环动画**。
- 快照尚未到达时不显示“0%”或空进度条，显示“正在获取任务状态…”。

**取消与提交**

- 下载 / 校验 / 准备阶段且 `cancellable == true`：显示“取消安装”；点击后立即禁用并改为“正在取消…”，等待快照进入 `Cancelled`，不能先显示“已取消”。
- `Cancelling`：按钮禁用，文案“正在取消…”，不重复发送取消。
- `Committing` 或 `cancellable == false`：取消按钮禁用，旁注“正在完成安装，无法取消”；提交窗口不可取消。
- `Failed`：隐藏取消，按 `retryable` 显示重试或只给日志；`Succeeded` 只代表安装就绪，启动状态另管。
- 取消和失败保留已校验文件；重试创建新任务并从检查缓存开始，由 application 决定，UI 不承诺断点续传。

**Qt Widgets 分工**

| 区域 | 组件 | 说明 |
| --- | --- | --- |
| 垂直步骤 | `StageList` + `StageRow` | 标准 `QVBoxLayout` 组合；圆点 / 标题 / 子状态；当前行展开字节数 |
| 未知总量 | `UnknownProgressNote` | 虚线边框 + “总量未知” + 已传输量；无动画 |
| 版本 | `VersionRow` + `QButtonGroup` | 安装中锁定；推荐 / 已验证来自快照 |
| 目录 | `SummaryRow` + 只读 `QLineEdit` | 用户可选中复制；安装中不可更改 |
| 空间 | `SummaryRow` | 需要 / 可用；未知值显示“未知”，不估算 |
| 取消 | `QPushButton#CancelInstall` | 白底红边；唯一位于固定底栏 |
| 说明 | `QLabel` | 取消 / 恢复 / 完成后边界；不堆重复提示 |

**键盘**：初始焦点在版本单选组；方向键切换版本；Tab 到目录、取消；安装中不自动把焦点移到取消，避免误触；Esc 不直接取消安装。

**预览**：[install.svg](../../resources/mockups/install.svg)。

### 5.3 设置

**目标**：用少量分组完成 Java、内存、游戏目录和启动后行为设置；错误在字段附近说明，保存前不写配置。

**信息层次**

1. Java：自动 / 手动；显示探测结果（版本、架构、来源）；手动路径无效时在字段下方说明并给出重新检测。
2. 内存：当前上限、允许范围、推荐值；单位 MB。
3. 游戏目录：当前路径、更改入口；冲突由 application 检查。
4. 启动后行为：保持启动器打开 / 启动后关闭启动器；游戏进程独立运行。
5. 固定保存栏：未保存状态、校验摘要、恢复默认、保存。

**Qt 组件**：`QGroupBox` + `QRadioButton`（Java 模式 / 启动后行为）；`QLineEdit` + `QPushButton`（手动路径 / 目录）；`QSpinBox`（内存，范围与步长来自快照）；`FieldRow` 内联错误；`PrimaryActionBar` 保存。`Ctrl+S` 保存；Esc 不静默丢弃修改；保存失败保留草稿并聚焦第一个无效字段。

### 5.4 日志与错误

**目标**：先告诉用户“发生了什么、我能做什么”，再提供可导出的脱敏日志；不把原始堆栈和凭据放在首屏。

**信息层次**

1. 错误摘要：用户能理解的原因、影响范围、下一步。
2. 操作：可重试时“重试”；始终提供“导出脱敏日志”；必要时“打开日志文件夹”。
3. 详情：稳定错误码、阶段、`taskId`、脱敏后的路径 / 版本；默认折叠或弱化。
4. 日志：只读、可选择、等宽字体；随通知更新，不轮询文件。
5. 空状态：没有错误时说明“最近没有错误”；没有日志时给出下一步。

**Qt 组件**：`InlineNotice`（错误摘要）、`QLabel` / 可折叠 `QFrame`（详情）、`QPlainTextEdit`（日志，`Cascadia Mono` / `Consolas`）、`QFileDialog` + application 导出命令。用户停在底部才自动跟随；向上滚动后停止跟随并显示“回到最新”。日志由 application 脱敏，UI 不拼接令牌、认证 URL 或完整命令行。

### 6.3 错误展示

错误码分类是建议，最终以 Codex 提供的稳定错误码为准。UI 负责“错误码 → 中文文案”，`retryable` 由 `AppError` 给出，UI 不解析消息文本。

| 错误类别（建议） | 展示位置 | 首屏重点 | 可用动作 |
| --- | --- | --- | --- |
| `Auth.*` | 首页账号区 / 日志 | 登录过期或授权失败 | 重新登录；不显示 token |
| `Network.*` | 安装 / 日志 | 网络中断或超时；已下载内容保留 | 可重试时“重试” |
| `Disk.*` | 安装 / 设置 | 空间不足或路径不可用 | 更改目录、释放空间；不自动重试 |
| `Permission.*` | 安装 / 设置 | 目录无写权限；给出具体路径 | 更改目录 |
| `Metadata.*` | 安装版本区 | 版本信息无效或不完整 | 刷新列表；不猜兼容性 |
| `Integrity.*` | 安装 / 日志 | 校验未通过；可复用部分保留 | 从缓存重试；不承诺断点续传 |
| `Launch.*` | 首页 / 日志 | 游戏未能启动 | 重试启动（若允许）、导出日志 |
| `Unknown` | 日志 | 通用说明 + 错误码 + 任务 ID | 导出日志；不显示原始异常全文 |

错误详情允许出现：错误码、阶段、`taskId`、脱敏路径、版本标签。禁止出现：访问令牌、认证 URL 中的凭据、完整启动命令行、未脱敏隐私路径。

## 7. 键盘与 100 / 150 / 200% 缩放验收

- 长中文路径可通过只读输入框选择复制，或 tooltip 查看完整值。

## 8. 后续所需 application 接口清单

**现状**：仓库中没有 `src/application`，也没有 `TaskSnapshot`、`AppError` 的真实头文件。以下全部是 UI 对 application 的需求清单与建议命名，不代表接口已存在。确认真实头文件与 Qt / MSVC 可构建后，才写 `src/ui` C++。

### 8.1 只读快照

| 快照（建议名） | 最小字段 | 用途 / 约束 |
| --- | --- | --- |
| `HomeSnapshot` | `account`、`instance`、`environment`、`primaryAction`、`primaryActionEnabled`、`blockingReasonCode`、`activeTask`、`launchSummary` | 首页一次渲染；主操作由 application 推导 |
| `AccountSnapshot` | `state`（未登录 / 登录中 / 已登录 / 已过期 / 错误）、`displayName` | 不含 token |
| `InstanceSnapshot` | `stableId`、`displayName`、`versionLabel`、`readiness` | 版本标签是展示值 |
| `EnvironmentSnapshot` | Java 状态（缺失 / 就绪 / 手动无效 / 检测中）、版本、架构、来源 | 兼容判断在 core / application |
| `LaunchSummary` | `memoryMb`、`closeLauncherAfterLaunch`、`lastLaunchState`（可选） | 首页摘要 |
| `TaskSnapshot` | `taskId`、`kind`、`instanceId`、`state`、`phase`、`phaseIndex` / `phaseCount`、`completedBytes`（可选）、`totalBytes`（可选）、`cancellable`、`error`（可选） | `totalBytes` 为空表示未知，UI 不猜 |
| `AppError` | 稳定 `code`、`phase`、`retryable`、安全上下文（脱敏）、`taskId` / `logRef` | UI 用 `code` 映射文案；不解析异常文本 |
| `VersionCatalogSnapshot` | 加载状态、`recommendedVersionId`、版本条目、错误 | 条目含 `id`、`label`、`channelLabel`、`verified`、可选 Java 要求展示值 |
| `InstallTargetSnapshot` | 展示路径、是否有效、`requiredBytes`（可选）、`freeBytes`（可选）、错误 | 目录由 application 校验；未知值明确为空 |
| `SettingsSnapshot` | Java 模式、手动路径、探测结果、内存当前 / 最小 / 最大 / 步长、游戏目录、启动后行为 | 范围与默认值来自 application |
| `LogSnapshot` | 错误摘要（可选）、日志条目（`severity`、`time`、`message`，已脱敏）、是否可导出 | UI 只显示与导出 |

补充：每次任务通知带 `taskId`；UI 在取消、重试、切换实例后忽略旧 ID；`TaskSnapshot` 不持久化运行中状态作为恢复依据；未知枚举显示“状态未知”+ 代码，不当作成功；凭据、token、完整认证 URL 不进入 UI。

### 8.2 命令 / 用例

| 目的 | 建议方法（待确认） | 说明 |
| --- | --- | --- |
| 首页主操作 | `invokePrimaryAction()` | application 决定登录 / 安装 / 准备 / 启动 |
| 登录 / 登出 / 刷新 | `signIn()`、`signOut()`、`refreshSession()` | 官方流程；登出清理凭据 |
| 版本目录 | `loadVersionCatalog()`、`selectVersion(id)` | 选择只是草稿 |
| 目录校验 | `validateInstallTarget(path)` | UI 打开 `QFileDialog`，application 判断 |
| 开始安装 | `startInstall(InstallRequest)` → `taskId` | 重试复用同一入口，application 检查缓存 |
| 取消任务 | `cancelTask(taskId)` | 只进入 `Cancelling`；不强行终止线程 |
| 启动游戏 | `startLaunch(instanceId)` | 与安装任务分离 |
| 设置读取 / 校验 / 保存 | `loadSettings()`、`validateSettings(draft)`、`saveSettings(draft)` | 字段错误由 application 返回 |
| Java 路径校验 | `validateJavaPath(path)` | 探测版本与架构由 application 完成 |
| 日志读取 / 导出 | `loadLogs()`、`exportLogs(destinationPath)` | UI 只选目标路径 |
| 打开日志目录 | `openLogFolder()` | application / 平台层执行 |

### 8.3 契约要求

- application 是任务状态唯一写入者；UI 只读快照，不维护第二份“安装中”布尔值。
- 取消 / 重试 / 切换实例后旧 `taskId` 的通知必须可忽略；不能靠最后一条通知猜当前任务。
- 取消请求只进入 `Cancelling`；`Cancelled` 必须在工作线程退出和清理后发出。
- `AppError.retryable` 由 application 决定；网络瞬态错误有上限退避，磁盘不足 / 无权限 / 无授权不可无限重试。
- 登录过期、登出后旧回调不得重新保存凭据；UI 不接触凭据。
- 安装与游戏运行状态分开；游戏退出不得触发重新安装。
- 快照不携带凭据；错误、日志、导出内容统一脱敏。
- UI 文案由 UI 侧统一维护（错误码 → 中文、阶段 → 中文）；application 不返回最终用户长句。

### 8.4 需要 Codex 确认 / 提供

1. `TaskSnapshot`、`AppError` 的真实头文件、字段、枚举与生命周期；`totalBytes` 如何表达“未知”。
2. `HomeSnapshot` / `PrimaryAction` 是否由 application 直接给出；首页主按钮如何避免 UI 重复推导。
3. 版本目录接口：推荐版本、`verified` 语义、Java 要求展示值。
4. 安装目标校验接口：路径规范化、权限、空间、所需字节。
5. 设置草稿 / 校验 / 保存接口，以及 Java 探测状态枚举。
6. 日志读取、脱敏导出、打开日志目录接口。
7. Qt / MSVC 的 CMake 目标名、Qt 模块（Widgets、Svg 是否可用）、构建与测试命令。
8. 信号线程归属、对象生命周期、关闭窗口时的协作取消契约。
