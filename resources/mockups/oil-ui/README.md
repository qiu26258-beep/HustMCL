# HustMCL · Oil UI 方向探索

状态：第二轮设计探索，暂定推荐 Campus Desk（校园工作台）。**推荐不等于用户已选定**；最终仍由用户复核。

HTML 只用于设计评审，不是产品技术栈。产品仍是 Windows 10/11 x64 的 C++20 + Qt 6 Widgets 原版 Minecraft 启动器；这些候选不引入 WebView、QML、JS 应用或远程资源。

## 方法与边界

- 品类：面向新手的桌面 Minecraft 启动器。基线期待：当前账号、当前实例、一个主操作、安装阶段、设置与日志入口。
- 标杆：本轮阅读了项目内对 PCL / HMCL 的架构记录，但**没有抓取或复用两者的运行画面、图标或主题素材**；不把它们的界面当作复刻目标。方向判断来自本产品的受众、等待安装的场景和校园主题。
- 调性：安静、精确、友好，不幼稚。能量偏安静，完成度偏精致，密度中等，分量中等，严肃度偏庄重；三个方向都留在这个调性内，在骨架、字体、色彩和主视觉上拉开。
- 共性：主操作只有一个；账号 / Java / 实例三种状态分开；未知总量只显示阶段与已传输量；不伪造安装、登录或性能结果。
- 示例数据只保留一个清楚的“设计预览 · 样例数据”标记，不再给每个字段重复贴小标签。

## 三个方向

### 01 Campus Desk / 校园工作台（暂定推荐）

- **北极星**：一张桌面先回答“我在用什么、是否准备好、下一步做什么”，而不是堆一组卡片。
- **生成引擎**：校园纸本 / 工作台。暖纸色、深红、细线稿、编号目录，来自“在校园里打开一台启动器”的具体场景。
- **首屏骨架**：左侧 216 编号导航；右侧一张 840 宽的桌面表面；桌面内左侧是当前实例、三行准备状态、启动摘要；右侧是一幅原创校园线稿和两条小提示；底部固定主操作条。
- **字体**：微软雅黑 UI + Segoe UI；实例名 30px，正文 13–14px，辅助 11.5–12.5px；数字等宽。
- **色彩**：`#F4F0E7` 纸底、`#FFFCF6` 桌面、`#23201C` 墨色、`#8C1D2F` 校园深红、`#4F6B52` 状态绿。
- **主视觉**：原创教学楼 + 树林线稿，只有屋顶用红色实心；不是学校校徽，也不是 PCL / HMCL 素材。
- **图标与控件**：不用通用图标库；导航用 01–04 编号和文字。主按钮 52px 高、7px 圆角；状态用勾选圆点和文字，不靠颜色 alone。
- **结构性突破**：把“准备状态 + 启动摘要”收进同一张桌面，减少卡片层级；主操作固定在底部，滚动内容不把它推走。
- **记忆点**：桌面右上的校园线稿和编号目录；主操作条在桌面底边，像一个明确的“开始”位置。
- **放弃**：卡片瀑布、彩色徽章堆叠、每项都配图标、装饰动画。
- **Qt 表达**：`QListWidget` 编号导航 + `QVBoxLayout` 页面骨架 + 一个 `QFrame#Desk` + `QGridLayout` 状态行 + 固定 `PrimaryActionBar`；安装页用 `StageList` 垂直步骤。全部是标准控件与少量 QSS，无自绘背景。
- **风险**：暖纸色如果处理不好会显得“米色模板”；本轮用单一桌面、编号导航和线稿把它拉回具体场景。

### 02 Launch Deck / 启动台

- **北极星**：把“启动”提到第一屏中心，状态像仪表一样横向排开。
- **生成引擎**：校园门廊 / 控制台。暗色启动带 + 红色立柱 + 青色状态点，来自“进入校园”的动作。
- **首屏骨架**：顶部品牌与横向导航；一块 992 宽的暗色启动带，左侧大字号实例名和主按钮，右侧几何门廊；其下三列状态轨；底部一行启动摘要与设置 / 日志链接。
- **字体**：Bahnschrift + 微软雅黑 UI；实例名 42px，状态值 20px。
- **色彩**：`#EFF3F4` 冷底、`#17282C` 暗带、`#B23A2E` 启动红、`#1F5C5A` 状态青。
- **主视觉**：原创门廊几何图形，三根红色立柱和一个青色圆；没有校徽或外部素材。
- **结构性突破**：没有侧栏，导航在顶部；主操作在首屏内，不使用固定底栏。
- **记忆点**：暗色启动带里的红色主按钮和门廊立柱对齐。
- **放弃**：侧栏、卡片网格、把状态拆成多个小卡。
- **Qt 表达**：顶部 `QToolBar` / `QHBoxLayout` 导航 + `QHBoxLayout` 启动带 + `QGridLayout` 三列状态；暗色面板是一个 `QFrame`，不需要自绘。
- **风险**：视觉更强，但暗色面板和顶部导航比 A 更偏离现有实现；新手需要重新学习导航位置。

### 03 Field Guide / 校园手册

- **北极星**：像翻一页校园手册：安静的纸面、宋体标题和一幅线稿；启动是页尾的一次明确落笔。
- **生成引擎**：校园印刷品 / 校样页。窄章节导航、纸面、细线、宋体标题、红色印章式方形（仅字母 H）。
- **首屏骨架**：左侧 168 窄章节栏；右侧一张 856 宽的纸面；纸面左列是实例、准备状态和主按钮；右列是教学楼与梧桐线稿、启动摘要。
- **字体**：SimSun 标题 + 微软雅黑 UI 正文 + Georgia 数字。
- **色彩**：`#ECEDDF` 纸底、`#FCFCF2` 纸面、`#26302A` 墨色、`#A33A2B` 印章红、`#2F4A3A` 森林绿。
- **主视觉**：原创教学楼与梧桐线稿；红色 H 方印只是应用字母标记，不是校徽。
- **结构性突破**：用章节式窄导航和纸面阅读顺序取代侧栏 + 卡片。
- **记忆点**：纸面右上的 H 方印和竖排感的章节编号。
- **放弃**：圆角卡片、阴影、通用图标库、满屏状态徽章。
- **Qt 表达**：`QTabBar` / 窄 `QListWidget` + `QScrollArea` + 纸面 `QFrame`；字体依赖 SimSun，需在所有目标 Windows 版本确认回退。
- **风险**：宋体标题更有辨识度，但更像阅读页面，启动器任务感较弱；字体回退和 200% 缩放风险高于 A。

## 暂定推荐：Campus Desk

理由按用户优先级排列：

1. **维护成本最低**：导航、页面骨架、桌面、状态行都能用标准 Qt Widgets 表达；没有暗色自绘面板、没有必须依赖宋体的标题、没有横向仪表布局的特殊约束。
2. **新手最易懂**：左侧固定导航 + 一个主操作 + 三行准备状态；不需要先理解顶部导航或章节结构。
3. **低资源**：纯色、细线、一个内联线稿；没有图片、阴影、渐变或持续动画。
4. **校园识别最稳**：暖纸色、深红屋顶、编号目录和校园线稿形成一套语言，且不依赖校徽或外部素材。
5. **可以延续到安装页**：同一张桌面可以变成“垂直步骤 + 本次安装信息 + 底部取消条”，状态语义不需要另造一套组件。

B 的启动带更有冲击力，适合作为后续可选视觉方向；C 的手册感更强，但更像阅读产品。两者保留在对比页供用户复核。

## 截图审阅记录

使用 `oil_ui_shoot` 实际截图并逐张查看，发现并修正：

- A 标题栏的窗口控制 SVG 被默认填充成黑色方块 → 给 SVG 补齐 `fill:none` / `stroke`。
- A 导航编号 02–04 对比度不足 → 改深；底部脚注、侧栏版本、页面脚注对比度不足 → 统一到可读的 `#6F675D`。
- B 底部摘要与页脚重叠 → 给主内容加明确的底部边界；移除标题上方眉标；脚注对比度修正。
- C 主按钮与说明文字重叠、右栏“打开设置”溢出纸面 → 移除重复说明、降低线稿高度、重排右栏；大量低对比小字改深，正文说明提到 13px。
- A 安装页的“校验文件 / 就绪”未来态标题对比度不足、恢复说明小于 13px → 改正文字色和字号。
- A 首页截图显示“启动摘要”在右栏、左侧留白过多 → 最终 SVG 把启动摘要移入左侧，右栏改为小提示；这是截图后做的结构修正。
